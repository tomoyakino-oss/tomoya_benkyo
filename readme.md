# CAD前レイアウトシミュレーター (Sales Layout Planner)

営業フロントエンドでの、顧客とのCAD前要件すり合わせ用Webツールです。
商談の場で、ブラウザ上で2D図面をレイアウトし、ワンクリックで3D表示に切り替えることができます。

## 特徴
- **1ファイル完結**: サーバー構築不要。ブラウザ（PC・スマホ）で即動作。
- **2D/3D連動**: 2Dで直感的に配置・ミリ単位の寸法調整を行い、即座に3Dで空間イメージを共有。
- **積算機能**: 配置したアイテムの概算見積をリアルタイム表示。
- **データ保存・読取**: 商談の途中でJSONとして保存し、次回に読み込んで再開可能。

## 使い方
1. `index.html` をブラウザ（Chrome, Edge, Safariなど）で開きます。
2. 左メニューからアイテムを選択し、中央のキャンバスをクリックして配置します。
3. 右パネルで寸法（W/D/H）やZ座標（浮揚高）を調整します。
4. 右上の「▶ 3D表示」ボタンで立体化します。

## 技術スタック
- HTML / CSS / Vanilla JavaScript
- [Three.js](https://threejs.org/) (3D描画)
